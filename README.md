# Portafolio de Natalia Marulanda — Análisis de datos

Sitio estático hecho con HTML, CSS y JavaScript. Diseño oscuro, elegante y creativo, con acentos morados y azules.

## Abrir en tu computador
1. Descomprime el archivo ZIP.
2. Entra en la carpeta `portafolio_analista_natalia`.
3. Haz doble clic en `index.html` para abrirlo en tu navegador.

No necesitas instalar programas para ver la página.

## Personalizar antes de publicar
- Revisa el correo y el enlace de GitHub en `index.html`.
- Actualiza la descripción de tus habilidades para que refleje tu nivel real.
- Cambia los estados de los proyectos cuando hayas terminado y documentado cada uno.
- No incluyas datos privados de tu trabajo; para el proyecto biomédico usa datos ficticios o autorizados y anonimizados.

## Publicar con GitHub Pages
1. Crea un repositorio nuevo en GitHub (por ejemplo, `portafolio-analisis-datos`).
2. Sube los archivos `index.html`, `styles.css`, `script.js` y `README.md` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y `/ (root)`, y guarda.
5. Espera a que GitHub Pages publique el sitio. La URL aparecerá en esa misma sección.

Los gráficos de la cabecera son ilustrativos y no representan resultados reales. Los proyectos se identifican como académicos, ideas o trabajos por documentar según corresponda.
